# v1.0.0 Linux 与容器基础环境

## 运行边界

- v1.0.0 使用单个 FastAPI/Uvicorn 进程和单个 SQLite 写入者。
- Windows 开发数据库目录通过 `DATABASE_HOST_DIR` 显式绑定到容器 `/data`；Linux 使用 `/var/lib/mental-health-assistant/data`。
- 数据库路径不存在、不可写或 schema 未就绪时，就绪检查失败；禁止回退到镜像层或系统临时目录。
- DeepSeek Key 仅通过服务端环境注入；pepper 通过只读 Docker secret 文件注入。
- 浏览器默认只可从本机 `127.0.0.1:8000` 访问；生产反向代理另在第 15 阶段设计并需用户确认。

## 安全默认值

- 运行用户固定为 UID/GID 10001，不使用 root。
- 容器根文件系统只读，仅 `/data` 和受限 `/tmp` 可写。
- 删除全部 Linux capabilities，启用 `no-new-privileges`。
- Uvicorn 使用 exec-form CMD、单 worker 和显式 forwarded proxy 信任范围。
- `.dockerignore` 排除 `.env`、`private`、数据库、Git、缓存、日志和个人任务文件。

## Windows 验证变量

```powershell
$env:DATABASE_HOST_DIR = 'E:\05_数据库与SQL\mental_health_assistant\data'
$env:AUTH_PEPPER_HOST_FILE = 'D:\SCY个人代码\assistant\private\auth_pepper.key'
```

## Linux 目标变量

```text
DATABASE_HOST_DIR=/var/lib/mental-health-assistant/data
AUTH_PEPPER_HOST_FILE=/etc/mental-health-assistant/secrets/auth_pepper
API_BIND_ADDRESS=127.0.0.1
API_PORT=8000
SESSION_COOKIE_SECURE=true
```

## 启动前置条件

1. 数据库目录和 pepper 文件已由部署用户准备，并设置最小权限。
2. 数据库迁移已完成且 `PRAGMA integrity_check`、`foreign_key_check` 通过。
3. API 已实现 `/health/live` 和 `/health/ready`。
4. 构建镜像会下载 Python 基础镜像与固定依赖，必须由用户明确执行或确认。
